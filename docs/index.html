PERSONAL GOOGLE DRIVE CONNECTION

自分のDriveを、
必要なときだけ。

Hermes Drive は、運営者自身の Google Drive を、ローカルで動く Hermes Agent に接続するための個人用 OAuth アプリです。

できること

  • Drive内のファイルを検索し、情報や内容を取得する。
  • 選んだファイルを実行端末へダウンロードする。
  • 利用者が依頼した場合に、アップロードや編集などを行う。

Drive全体にアクセスできる権限を使いますが、全ファイルの自動同期は行いません。ファイルの変更・削除・共有設定の変更は、利用者が求めた場合に限ります。

利用する人

運営者本人の利用を目的としています。一般向けの利用登録やサービス提供は行っていません。

このWebサイトは説明用です。Googleへのログイン、Driveへの接続、ファイルのアップロードをこのサイト上で行うことはありません。

データの扱い

認証情報と取得したファイルは、Hermesを実行する端末側で管理します。検索結果や依頼に必要な内容は、設定されたAIサービスで処理される場合があります。取得したデータが常に端末内だけで完結する、という意味ではありません。

この説明サイトに、Driveのファイルや認証情報を掲載・保存することはありません。

利用条件

運営者本人が、自身のGoogleアカウントとデータを管理する目的で使用します。Googleおよび利用する外部サービスの規約・データ取扱条件に従い、第三者の権利を侵害する用途には使用しません。

重要な変更を依頼する前に内容を確認し、必要なバックアップを用意してください。継続提供や無停止動作を保証するものではありません。データの扱いはプライバシーポリシーに記載します。
